# Jia him 本地文章工作台

这是一个只在本机运行的 Next.js 编辑器。它不会部署到 Vercel，也没有远程登录或 GitHub App。

## 启动

从仓库根目录运行：

```bash
pnpm dev:admin
```

服务固定监听 `http://127.0.0.1:3000`。默认读取当前 monorepo 根目录；如从特殊目录启动，可在本地环境中设置：

```bash
LOCAL_REPOSITORY_ROOT=/absolute/path/to/about-me
NEXT_PUBLIC_SITE_URL=http://127.0.0.1:5173
```

管理端没有账号登录，所有读写与 Git 接口都只接受回环地址和严格同源请求。不要把它绑定到 `0.0.0.0`、私网地址或公网地址。

## 编辑器与站点设置

- 左栏是文章搜索、分类和列表，可收起为快捷栏。
- 中栏是 CodeMirror Markdown 源码编辑器，`Cmd/Ctrl+S` 保存。
- 右栏是安全实时预览、文章大纲和可定位源码行的 SEO/GEO 完整性检查，不执行正文中的原生 HTML。
- 顶栏可切换“文章管理 / 站点设置”。设置草稿按配置哈希保存在浏览器；哈希冲突不会覆盖磁盘内容。
- 站点设置使用 Schema v2；读取旧 v1 配置或草稿会先确定性迁移，保存只写 v2。迁移失败的旧草稿保留供人工恢复。
- 栏目向导用事务同时更新 `config/site.config.json` 与栏目首页；归档前显示文章数，归档不删除或移动文章。
- 品牌资源只写入 `docs/public/images/site/`，并在保存配置前保留为设置草稿。
- 每个设置模块都可在右侧预览真实 VitePress 页面；默认聚焦当前模块，也可切换完整页面、桌面/平板/手机宽度、75%/100%/125%/适应缩放，以及全屏检查。SEO、Feed、robots 和 `llms.txt` 等非视觉配置显示确定性产物预览。
- 未保存内容会写入浏览器本地恢复副本；成功保存后自动清除。
- “保存设置”只原子写入本地文件，不会自动提交或推送。保存后右侧自动显示当前设置会话的精确 Diff，顶部“提交设置并推送”是独立的下一步。

## Git 工作流

顶部展示真实分支和变更数。“查看差异”只读取当前文章的 diff 与历史。

“提交并推送”执行受限流程：

1. 检查 detached HEAD、冲突、merge/rebase/cherry-pick 和远端状态。
2. 位于默认分支时创建 `content/YYYY-MM-DD-slug` 分支。
3. 只暂存当前文章和本次编辑会话上传的媒体。
4. 使用 `[Human] ` 前缀提交，并通过本机 Git/SSH 推送。
5. 使用已登录的 `gh` 创建或复用 Pull Request。

站点设置使用同一条受限 Git 流程，但发布范围由服务端设置会话生成：浏览器不能提交路径列表。会话绑定仓库真实路径、分支、HEAD、配置哈希与开始前的脏文件，只允许本次保存、栏目事务和品牌资源上传实际产生的路径；会话开始前已有改动的文件会在界面中明确阻止发布。设置分支命名为 `content/YYYY-MM-DD-site-settings`，成功创建可读 Pull Request 后会话立即失效。

如果暂存区已经包含范围外文件，流程会停止，不会自动 reset 或取消暂存。界面不提供 force push、reset、rebase、stash、clean、覆盖文件 checkout 或全仓暂存。

“合并并发布”是单独对话框，显示目标分支、来源分支和待确认的 PR head OID。服务端会重新读取 PR 并要求 OID 一致、工作区与暂存区为空、upstream 存在、本地与远端同步且检查成功，随后才运行 squash merge；任何条件变化都会停止。成功合并后，Vercel 根据 `main` 更新发布公开站点。

## 前置条件

- Node.js 22+
- pnpm 10
- 已配置 Git remote 和 SSH 凭据
- 已安装并登录 GitHub CLI：`gh auth status`

## 已知限制

- 三栏支持拖拽和键盘调整，布局与滚动同步开关保存在浏览器本地。
- 滚动同步按滚动比例工作，精确的标题级双向映射仍属于后续优化。
- 不提供删除文章、批量发布、图片资源库或多人协作。

## 公开 SEO / GEO 产物

公开站点构建会从同一份配置和可见文章生成 `robots.txt`、`sitemap.xml`、`feed.xml`、canonical、Open Graph 和 JSON-LD。AI 搜索发现与模型训练权限分别配置。`llms.txt` 是实验性、非统一标准的可选输出，默认关闭。

内容完整性开关同时控制编辑器提示和公开构建门禁：作者与发布时间缺失属于阻断错误，更新时间、图片替代文本和站外引用缺失属于显式警告。启用的公开集成只检查所声明环境变量是否存在，不读取或返回秘密值。

逐字段的公开消费方、预览类型、迁移规则和验证文件见 [站点设置契约与消费矩阵](../../docs/architecture/settings-contract.md)。
