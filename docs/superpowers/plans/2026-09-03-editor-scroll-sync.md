# Editor Preview Scroll Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the existing “滚动同步” control perform real, bidirectional proportional scrolling between CodeMirror and the Markdown preview.

**Architecture:** `AdminApp` owns the enabled state and the latest versioned scroll event. `MarkdownEditor` and `PreviewPane` publish user scroll ratios and apply only events originating from the opposite pane. Each recipient suppresses the scroll event caused by applying a remote ratio so synchronization cannot bounce indefinitely.

**Tech Stack:** React 19, TypeScript, CodeMirror 6, Vitest, Testing Library.

**Spec:** Approved bounded design in the 2026-09-03 task conversation; no standalone specification file.

## Global Constraints

- Synchronization is bidirectional while enabled and fully independent while disabled.
- The calculation uses `scrollTop / (scrollHeight - clientHeight)` and clamps to `0...1`.
- Programmatic recipient scrolling must not publish a second synchronization event.
- No dependency additions.
- Do not commit, push, or create a PR; the user has not authorized Git writes.
